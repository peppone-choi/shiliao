# 史料 · shiliao

**삼국지 시대 사료 1,271권을, 기억이 아니라 인용으로 답하게 하는 인덱스.**

```console
$ shiliao 白馬義從
[後漢書 卷073 劉虞公孫瓚陶謙列傳 第六十三]
  …皆乘白馬，以為左右翼，自號「《白馬義從》」。烏桓更相告語，避白馬長史…
[三國志 卷06 魏書·董二袁劉傳]
  …騎爲兩翼，左右各五千餘匹，《白馬義從》爲中堅，亦分作兩校，左射右，右射左…

$ shiliao 白毦兵
✗ 「白毦兵」 — 삼국지 시대 사서에서 미검출. 사료 근거 없음(추측으로 채우지 말 것).
```

두 번째 출력이 이 도구의 존재 이유다.

---

## 왜 만들었나

삼국지 게임을 만들다 병종 목록을 적었다. 백마의종, 함진영, 등갑병, 남만 코끼리 부대.
전부 "아는" 것이었다. 그래서 전권을 받아 확인해봤다. 셋이 틀렸다.

| 내가 안다고 여긴 것 | 실제 |
|---|---|
| 白馬義從은 전승이겠지 | **정사다.** 後漢書 卷73 「自號白馬義從。烏桓更相告語，避白馬長史」 — 오환족이 "백마를 피하라" 서로 일렀다는 대목까지 있다 |
| 燒當羌·參狼羌은 못 찾겠다 | **46건·4건 있다.** 내가 卷87 하나만 봤을 뿐이다 |
| 남만엔 코끼리 부대가 있다 | **없다.** 後漢書의 유일한 「象兵」이 「或執銅鏡以象兵」 — 동경을 병기처럼 *보이게 했다*는 동사다 |
| 白毦兵은 진수 정사에 있다 | **1,271권 어디에도 없다** |

거꾸로, 내 기억에 아예 없던 것들이 나왔다. 華陽國志의 **赤甲軍**과 **連弩士**(「赤甲軍常取其民。
亮亦發其勁卒三千人為連弩士」), 諸葛亮 연노의 제원 **元戎**(「以鐵為矢，矢長八寸，一弩十矢俱發」),
오나라 **解煩兵**의 좌·우부 편제(「立解煩兩部，詳領左部、綜領右部督」).

그리고 병종보다 큰 것 하나 — 後漢書 百官志에 부대 편제가 봉급 등급과 함께 통째로 있었다.

```
部 校尉  比二千石  →  部 軍司馬  比千石  →  曲 軍候  比六百石  →  屯 屯長  比二百石
```

부대 규모 단위를 지어낼 필요가 없었다. 1,900년 전에 이미 적혀 있었다.

**LLM은 삼국지를 안다. 다만 아는 것과 지어낸 것을 스스로 구별하지 못한다.**
이 도구는 그 경계를 계측 가능하게 만든다.

전부 zh.wikisource의 public domain 원문이다. **이 레포는 사료를 배포하지 않는다** — 받는
스크립트만 담고, 원문은 `~/.shiliao`에 남는다.

몇 가지가 우연이 아니라 값어치가 크다.

- **三國志 65권엔 裴松之注가 붙어 있다.** 『魏略』『英雄記』『九州春秋』『江表傳』… 오래전 흩어진
  200여 종 인용서의 집록을 함께 받는 셈이다. 卷30은 동이전만이 아니라 裴注 인용
  **『魏略』西戎傳**까지 담아, 한 권에 한반도·왜와 서역이 같이 들어 있다.
- **後漢書 卷109~113 = 郡國志, 卷114~118 = 百官志.** 이 판본은 續漢書 志를 後漢書 권번호로
  이어 매긴다. 105군국의 속현 목록과 관직·질석 표가 권 번호만으로 잡힌다.
- **資治通鑑은 본문에 「公元一九一年」을 달고 있다.** 연호와 서기가 원문에서 대응된다.

## 설치

**클론이 곧 설치다.** 코퍼스(`corpus/`, 1,275권)와 만들어 둔 인덱스(`index.db`, 85MB)가
저장소에 함께 들어 있어 받자마자 질의된다. 다운로드도 빌드도 없다.

```bash
git clone <repo> shiliao && cd shiliao
python3 -m shiliao.index 白馬義從
```

`index.db` 는 Git LFS 로 관리한다 — 85MB 바이너리를 일반 git 객체로 넣으면 다시 만들 때마다
히스토리에 85MB 가 영구히 쌓인다. 클론 전에 `git lfs install` 이 되어 있어야 한다.
없으면 `index.db` 자리에 포인터 텍스트가 놓이고, 그때는 `python3 -m shiliao.index` 로
`corpus/*.txt` 에서 1분이면 다시 만들 수 있다.

<details><summary>예전 방식 — 코퍼스를 직접 받기</summary>



Python 3.8+ 외엔 아무것도 필요 없다. 의존성 0 — SQLite FTS5는 표준 라이브러리다.

```bash
git clone https://github.com/peppone-choi/shiliao && cd shiliao
python3 -m shiliao.fetch      # ~20분. 원문 124MB → ~/.shiliao
python3 -m shiliao.index      # ~1분. 인덱스 85MB
```

한 줄 별칭이 편하다.

```bash
echo "alias shiliao='python3 -m shiliao.index'" >> ~/.zshrc
```

받는 도중 끊겨도 괜찮다. 다시 실행하면 있는 파일은 건너뛰고 이어받는다.
위키소스는 병렬도를 올리면 **오류 없이 빈 응답**을 주니 `--jobs`를 4 위로 올리지 마라.

</details>

## 쓰기

```bash
shiliao 突騎                        # 전체
shiliao 突騎 --era                  # 삼국지 시대 사서만 (漢書·史記·隋書 등 배경서 제외)
shiliao 連弩 --book 華陽國志
shiliao 屯長 --book 後漢書 --limit 3
```

`SHILIAO_HOME`으로 코퍼스 위치를 옮길 수 있다.

### 걸려 넘어지는 것 셋

**1. 繁體로 검색해라.** 코퍼스는 전부 정체자다. `雒阳`은 0건, `雒陽`은 잡힌다.
CHGIS 같은 간체 데이터셋과 대조할 때 이것 하나로 몇 시간을 날릴 수 있다.

**2. 매칭은 글자 단위다. 스니펫을 읽어라.** `屯長`(후한 관직)을 찾으면
「西**屯長**安」— *장안에 주둔했다* — 도 걸린다. 한문엔 띄어쓰기가 없어 인덱스가 볼 수 없는
경계다. **건수만 세는 것은 근거가 아니다.**

**3. 0건은 "이 코퍼스에 없다"지 "기록에 없다"가 아니다.** 水經注·東觀漢記·太平御覽은
색인되지 않았다(위키소스에 없거나 제목 형식을 확인하지 못했다). 어디까지 찾았는지를
함께 말해라.

## 어떻게 작동하나

한문엔 공백이 없다. 그래서 SQLite의 기본 토크나이저는 **한 권을 토큰 하나**로 본다.
`trigram` 토크나이저는 CJK를 다루지만 3자 미만 질의를 놓친다 — 「義從」이 안 잡힌다.

그래서 **글자마다 공백을 넣어 색인하고 구(phrase) 질의로 되돌린다.**

```
색인:  白 馬 義 從 爲 中 堅
질의:  "義 從"        →  정확히 일치, 길이 무관
```

인덱스가 두 배로 커지는 대신(85MB) 어떤 길이의 한자열도 정확히 잡힌다. 의존성은 여전히 0이다.

편명은 위키텍스트 헤더의 `section=`에서, 三國志의 입전 인물은 `notes=`에서 뽑는다.
그래서 결과가 「卷55」가 아니라 「卷55 吳書·十二虎臣傳 (程普 黃蓋 韓當…)」로 나온다.

## AI 에이전트와 함께 쓰기

특정 도구 전용이 아니다. 네 프로바이더가 전부 MCP를 말하므로 서버는 하나다 —
`shiliao/mcp_server.py`, 표준 라이브러리만 쓰는 약 130줄이다. 노출하는 도구도 하나,
`search_sources(term, book?, era?, limit?)`.

```bash
python3 -m shiliao.mcp_server              # stdio  — Claude Code · Codex · Gemini CLI
python3 -m shiliao.mcp_server --http 8787  # HTTP   — ChatGPT 커넥터 등 원격 클라이언트
```

| 클라이언트 | 붙이는 법 |
|---|---|
| **Claude Code** | 스킬이 정본이다 — 이 저장소를 통째로 `~/.claude/skills/historical-sources` 로 클론하면 끝. MCP 로 붙이려면 `mcp.json` 을 프로젝트 `.mcp.json` 으로 복사 |
| **Codex** | `codex-config.toml` 내용을 `~/.codex/config.toml` 에 붙여 넣는다 |
| **Gemini CLI** | `mcp.json` 을 `~/.gemini/settings.json` 의 `mcpServers` 에 병합 |
| **Claude 데스크톱 앱** | 아래 A |
| **Claude 웹 · ChatGPT 웹/앱 · Gemini 웹/앱** | 아래 B (전부 같은 URL 하나) |

규칙은 `INSTRUCTIONS.md` 한 곳에 있고 `AGENTS.md`·`GEMINI.md`·`CLAUDE.md` 는 그 심볼릭 링크다.
프로바이더별로 규칙이 갈라지면 갈라진 만큼 어긋나기 때문이다. MCP `initialize` 응답과
도구 설명에도 같은 문구를 실어, 지침 파일을 안 읽는 클라이언트도 규칙을 받는다.

핵심 규약은 하나다 — **0건은 UNKNOWN이지 기억으로 채울 자리가 아니다.**
그리고 正史와 演義를 뭉뚱그린 한 문장으로 답하지 않는다. 등급이 다른 주장은 따로 세운다.

### A. 데스크톱 앱 (로컬 stdio)

`mcp.json` 의 `mcpServers` 블록을 설정 파일에 병합하고 경로 두 개를 실제 값으로 고친다.
Claude 데스크톱 앱을 완전히 종료했다 다시 켜면 도구 목록에 `shiliao` 가 뜬다.

```
macOS    ~/Library/Application Support/Claude/claude_desktop_config.json
Windows  %APPDATA%\Claude\claude_desktop_config.json
```

### B. 웹·모바일 앱 (원격 커넥터)

브라우저와 폰에서 도는 클라이언트는 당신 기계의 프로세스를 실행하지 못한다. stdio 가 아니라
**공개된 HTTPS 엔드포인트**가 필요하다. 인덱스는 당신 기계에 있으므로, 서버를 띄우고 터널로
노출하는 형태가 된다. 아래 넷이 전부 이 URL 하나를 본다.

```bash
export SHILIAO_TOKEN=$(python3 -c 'import secrets;print(secrets.token_urlsafe(32))')
export SHILIAO_HOME=/절대/경로/코퍼스
python3 -m shiliao.mcp_server --http 8787 0.0.0.0
cloudflared tunnel --url http://localhost:8787       # 또는 ngrok http 8787
echo "https://<터널이-출력한-주소>/$SHILIAO_TOKEN/"   # ← 커넥터에 넣을 URL
```

**토큰을 URL 경로에 넣는 이유**: 커넥터 UI 들은 정적 `Authorization` 헤더를 넣는 칸이 없다.
클로드는 OAuth 클라이언트 ID/시크릿, 제미나이는 DCR 또는 자격증명을 묻는다. 그래서 서버가
`Bearer` 헤더와 URL 경로 둘 다로 같은 토큰을 받는다. URL 자체가 열쇠이므로 아무 데나 붙여넣지 마라.

| 클라이언트 | 넣는 곳 |
|---|---|
| **Claude 웹 / 데스크톱** | Customize → Connectors → `+` → 이름과 URL 입력 → Add |
| **ChatGPT 웹** | 설정 → Connectors → 맨 아래 Advanced settings → Developer Mode 켜기 → 설정 → Apps & Connectors → Create → 엔드포인트 입력 |
| **ChatGPT 앱** | 커넥터 추가는 웹에서만 된다. 추가해 두면 같은 계정의 앱에서 쓸 수 있다 |
| **Gemini 웹** | gemini.google.com → 하단 설정 및 도움말 → Connected Apps → "Custom apps for Spark" 에 URL 입력 |
| **Gemini 앱 (Android)** | 같은 Connected Apps 화면. 프롬프트에서 `@` 로 커스텀 앱을 지정해 부른다 |
| **Gemini Enterprise** | 커스텀 MCP 서버 데이터스토어로 등록 |

클라이언트별로 걸리는 지점:

- **ChatGPT** — 개발자 모드 대화에서는 서버가 노출하는 도구를 그대로 쓰지만, 딥리서치·기업지식
  경로는 `search`(인자 `query`)와 `fetch`(인자 `id`) 두 도구를 이름과 모양까지 강제한다.
  그래서 이 서버는 `search_sources` 외에 그 한 쌍도 함께 노출한다. 개발자 모드는 유료 플랜이고,
  워크스페이스 계정이면 관리자만 켤 수 있다.
- **Gemini** — 개인 구글 계정이어야 하고(직장·학교 계정은 안 된다), Keep Activity 가 켜져 있어야
  붙는다. **StreamableHTTP 전용이고 레거시 SSE 는 안 받는다** — 이 서버가 기본으로 JSON 한 방을
  돌려주므로 그대로 맞는다.
- **Claude** — 커넥터는 앤트로픽 클라우드에서 당신 서버로 접속한다. 즉 사설망 주소는 안 되고
  공개 인터넷에서 닿아야 한다. 터널이 필요한 이유가 이것이다.

그리고 공통으로 셋:

- **토큰 없이 `0.0.0.0` 에 띄우지 마라.** 그 순간 주소를 아는 누구나 당신 기계의 인덱스를
  조회한다. `SHILIAO_TOKEN` 이 설정돼 있지 않으면 서버가 기동 로그에 「인증 없음」이라고 찍는다.
- **당신 기계가 꺼지면 커넥터도 죽는다.** 상시로 쓰려면 어딘가에 올려 둬야 하는데, 그때는
  코퍼스 재배포가 되는지부터 확인해라(아래 라이선스 항목).
- **터널 주소는 대개 재시작마다 바뀐다.** 고정 주소가 필요하면 named tunnel 을 쓴다.
